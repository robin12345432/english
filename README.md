# English – Wörter lernen

Gebaute Version einer persönlichen Lern-App (PWA) für Englisch: Wörter mit Spaced Repetition, Eintippen der
deutschen Bedeutung, englische Aussprache mit der Stimme des Geräts. Nicht kommerziell. Der Quellcode liegt lokal.
